# Contributing

Thank you for taking an interest. Bug fixes and translation corrections are very welcome.

- Found a bug, a typo or a patch that won't build? Please open an issue at https://github.com/Pat227-spc/stafy-patches/issues
  or here, or send a pull request.
- Please say which game and version, and how to reach the spot in-game if you can.
- Pull requests that fix build scripts, tools or obvious typos are gladly accepted.

Most of the text in these games is the work of the original translators (see the Credits in README.md).
When suggesting changes to their text, please respect their work: keep changes small, explain why, and fix
clear mistakes rather than rewriting their style. If an original author asks for something to be changed or
removed, their wishes come first.
