# tools/bin
Required by build.sh: `armips`, `flips` (bundled Linux builds), `Atlas.exe`, `lzss.exe` (download, see ../README.md).
On Windows (Git Bash/MSYS2) use `armips.exe` and `flips.exe` instead.
These are third-party tools by their original authors: armips by Kingcom (MIT), Floating IPS by Alcaro (GPL-3.0),
Atlas by Klarth, lzss by CUE.
